# User Management System in AdonisJS v6

A school project focused on building a fully functional administration and user management system using the AdonisJS framework.

## 🛠 Tech Stack
* **Framework:** AdonisJS v6 (TypeScript)
* **Database:** SQLite
* **ORM:** Lucid ORM
* **Development Environment:** WebStorm + WSL (Ubuntu)

## 🚀 Getting Started

1. **Install dependencies:**
   ```bash
    npm install

2. **Run database migrations:**
   ```bash
   node ace migration:run

3. **Start the development server:**
    ```bash
    node ace serve --watch
    ```

The application will run at http://localhost:3333.


## ⚙️ Features
**User Authentication:** User login and access protection.

**User Management (CRUD):** Displaying a list of registered users from the SQLite database, with functionality to add and delete accounts.
